# Каркас агента

Каркас собран copilot из ответов проекта. Потолки и инструменты взяты из `config.json`, а он заполнен по листу потолков и паспорту инструментов.

## Что уже есть

- Цикл решений. Модель называет действие, а исполняет его код: инструмент с неизвестным именем, действие сверх прав и повтор не исполняются.
- Пять потолков: шаги, деньги, время, артефакты и размер входа. Исход «остановлено по пределу» нельзя спутать с «сделано». Повтор после предела запрещён.
- Ключ идемпотентности для инструментов класса «с ключом». Повторный запрос с тем же `key` не порождает второго действия.
- Ручная очередь. Туда уходят остановленные по пределу прогоны, спорные случаи и действия, которые нужно подтвердить.
- Журнал в `agent.db`. По каждому шагу пишутся модель, токены, цена и заметка.
- Адрес для проверок и атак: `POST /run`.

## Запуск

```
pip install fastapi uvicorn httpx pytest
python -m pytest tests -q
uvicorn server:app --host 127.0.0.1 --port 8100
```

## Что дописать

1. Реализации инструментов в `tools.py`, по одной функции на каждый инструмент из `config.json`.
2. Ключ идемпотентности из бизнес-полей: замените `idempotency_key`.
3. Адреса моделей в `config.json`. Ключи хранятся только в переменных окружения.
