# Команды copilot

Запуск из корня пакета: `python -m app.cli <команда>`.

| Команда | Что делает |
|---|---|
| `list` | Список проектов |
| `new "Название" --start N [--desc "..."] [--domain <id>]` | Новый проект с шага N |
| `domains` | Список отраслей с обезличенными примерами |
| `status <pid>` | Готовность проекта по шагам |
| `questions <pid> <шаг>` | Вопросы шага: текст, зачем, наводящие, пример |
| `answer <pid> <шаг> <вопрос> --text "..."` | Ответ текстом |
| `answer … --rows-json '[["…","…"]]'` | Ответ таблицей |
| `answer … --unknown` / `--skip` `[--note "..."] [--owner "роль"]` | «Не знаю» / «Сознательно опускаю» с владельцем |
| `risks <pid>` / `risk-owner <pid> <id> --owner "роль"` | Рекомендации по рискам и их владельцы |
| `recs <pid>` | Три самых полезных рекомендации сейчас |
| `rec <pid> <id> --action start\|done\|defer\|dismiss\|reopen [--reason "..."]` | Действие с рекомендацией |
| `debrief <pid> <шаг>` | Итог шага |
| `build <pid> <шаг>` | Документ шага |
| `passport <pid>` | Паспорт проекта |
| `prototype <pid>` | Схема агента, сценарий n8n, каркас на Python |
| `workspace <pid> --path "<папка>" [--cloud]` | Подключить разработку Junior Pilot (только чтение) |
| `scan <pid>` | Проверка разработки кодом |
| `target <pid> --url <адрес стенда>` | Адрес агента для проверок и атак |
| `attack-arm` / `attack-launch` | Испытания — только по [attacks.md](attacks.md) |
| `defense <pid>` | Каркас защиты перед ЛПР |
