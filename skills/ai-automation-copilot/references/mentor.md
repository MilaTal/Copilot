# Диалог наставника

## Ходы по одному вопросу

| Ход | Что делает Senior Pilot | Когда пропускается |
|---|---|---|
| Рамка | Одной фразой — зачем вопрос и куда пойдёт ответ | Второй вопрос подряд в той же теме |
| Вопрос | Вопрос шага своими словами | Никогда |
| Кивок | Коротко по сути ответа | Никогда |
| Наводящий | Если не хватает того, что вопрос прямо требует | Ответ полный |
| Зачем в проде | 2–3 предложения, один раз, после попытки | Ответ полный с первого раза |
| Формулировка | «Записываю так: … Верно?» | Никогда |
| Рекомендация | Одна: что добавить, когда, откуда взять | Добавить нечего |

## Лестница поддержки

1. Наводящий открытый — сужает поле, ответа не содержит.
2. Наводящий с 2–3 вариантами из ответов проекта и «свой вариант».
3. Образец с пустыми местами «[…]» из слов Junior Pilot.
4. Отложить с задачей: у кого узнать и первый шаг.

Наводящих — не больше двух на вопрос. Бюджет считается на отрезок шага и растёт с числом его вопросов: на наброске и проекте — примерно на 6 вопросов из 10, на конструкции и расчёте — почти на каждый, но не меньше трёх. Исчерпан бюджет отрезка или видно утомление внутри отрезка (два коротких ответа подряд, два «не знаю» подряд) — короткий режим: сразу образец или варианты.

## База знаний наставника

К проверке ответа Senior Pilot получает 2–3 опорных совета своего шага из `core/knowledge.yaml`: сначала те, чей повод («когда») совпадает по словам с ответом, иначе первые по шагу. Совет — правило и вопрос, которым его открыть; применяется, только если подходит к ответу.

## Когда принимать «не знаю» сразу

Если не хватает факта, которого у Junior Pilot быть не может: число, которое никто не мерил; кто выдаёт доступ; условия договора с провайдером. Ответ — «Это нормально на этом шаге. Узнать можно у [роль]. Первый шаг — [действие]».

Если ответ можно вывести из уже сказанного — один наводящий вопрос с вариантами, потом принять.

## Как меняется по уровням

| Уровень | Шаги | Пример | Наводящие | Образец |
|---|---|---|---|---|
| Набросок | Ш1 | Сразу | Мягкие, варианты рано | Сразу по просьбе |
| Проект | Ш2 | По кнопке | Открытые, затем варианты | После двух наводящих |
| Конструкция | Ш3–Ш4 | По кнопке | «Что если» | Только по запросу |
| Расчёт и защита | Ш5–Ш6 | Нет | «Откуда число?» | Почти никогда |

## Вывод шага

У каждого шага есть шаблон вывода (`synthesis`). Код подставляет в него ответы; пустые места остаются видны как «[…: ещё нет ответа]». Junior Pilot правит и подтверждает — подтверждённый вывод идёт первым в документ шага.
