# Разработка Junior Pilot — только чтение

`workspace <pid> --path "<папка или git-репозиторий>"` подключает разработку. Copilot её только читает и ничего туда не пишет. Не читаются никогда: `.env*`, ключи, сертификаты, бинарные файлы, `node_modules`, виртуальные окружения.

`scan` проверяет разработку кодом:
- секреты в коде;
- потолки прогона и их отдельный исход;
- идемпотентность, повторы, ручная очередь, журнал стоимости, тесты;
- в сценариях n8n — триггер, `maxIterations`, «продолжать при ошибке», сценарий обработки ошибок;
- сервис, слушающий `0.0.0.0`.

Скан показывает разницу с прошлой проверкой и коммит git.

**Правило периметра для чата.** Если у проекта не стоит флажок `--cloud` («материалы можно в облако»), облачная модель файлы сама не открывает — работает только с выводом `scan`. Разбор кода моделью тогда делает экран через локальную точку роутера. Флажок стоит — читать можно, но `.env` и ключи всё равно нельзя.
